# УЛЬТИМАТИВНОЕ ТЕХНИЧЕСКОЕ ЗАДАНИЕ (PRODUCTION RELEASABLE SPEC v5.0)
**Проект:** «Спасение Розы: Шахта надежды»
**Платформа:** Яндекс Игры (HTML5 / Vanilla JS / CSS3)
**Жанр:** RPG-Кликер с конвейерной механикой, эволюцией предметов и нарративом
**Layout:** Адаптивный горизонтально-вертикальный монолит. Все размеры элементов масштабируются через CSS `rem` и `vw/vh`, сохраняя идеальные пропорции на ПК (16:9) и смартфонах (9:16).

## 1. АРХИТЕКТУРА ДАННЫХ И ИСТОЧНИК ПРАВДЫ (JS STATE)

### Структура объекта State в `GameEngine`
```javascript
state = {
  gold: 0,
  checkpoint: 1,       // Текущий чекпоинт (1-50)
  subLevel: 1,         // Номер стены на текущем чекпоинте (1-5)
  gameState: 'MINING',  // Текущая фаза: 'MINING', 'BOSS_WAIT', 'BOSS_FIGHT'
  
  // Комбо-система для виральности (ТикТок ASMR)
  comboCount: 0,       // Текущее количество последовательных кликов
  lastClickTime: 0,    // Метка времени последнего клика (ms)

  // ВКЛАДКА 1: ИНСТРУМЕНТЫ ДОБЫЧИ (Влияют на урон по стенам)
  upgrades_mining: {
    pickaxe: 0,        // Кирка (Базовый инструмент)
    helmet: 0,         // Каска шахтера (Замок: pickaxe >= 5)
    dynamite: 0        // Связка динамита (Замок: helmet >= 5)
  },
  
  // ВКЛАДКА 2: БОЕВОЕ СНАРЯЖЕНИЕ (Влияют на урон по боссам)
  upgrades_combat: {
    sword: 0,          // Меч (Базовое оружие)
    shield: 0,         // Щит (Замок: sword >= 5)
    armor: 0           // Доспех (Замок: shield >= 5)
  },
  
  // ВКЛАДКА 3: НАЕМНИКИ И АВТОМАТИЗАЦИЯ (Влияют на пассивный доход)
  upgrades_workers: {
    miner_pakhom: 0,   // Дед Пахом (Дешевый рабочий)
    miner_team: 0,     // Бригада парней (Замок: pakhom >= 5)
    miner_golem: 0     // Магический голем (Замок: team >= 5)
  },
  
  boosts: {
    ragePotion: 0      // Зелья ярости х3 урона (за рекламу)
  }
}
```

## 2. МАТЕМАТИКА РАСЧЕТА ХАРАКТЕРИСТИК И БАЛАНСА

### А. Формула Силы Кирки (`clickPowerPickaxe`)
* `Power_Pickaxe = state.upgrades_mining.pickaxe == 0 ? 0 : Math.floor(1 * (1.14 ^ state.upgrades_mining.pickaxe))`
* `Power_Helmet = state.upgrades_mining.helmet == 0 ? 0 : Math.floor(4 * (1.16 ^ state.upgrades_mining.helmet))`
* `Power_Dynamite = state.upgrades_mining.dynamite == 0 ? 0 : Math.floor(16 * (1.18 ^ state.upgrades_mining.dynamite))`
* **Итоговый урон по стенам:** `clickPowerPickaxe = 1 + Power_Pickaxe + Power_Helmet + Power_Dynamite`

### Б. Формула Силы Меча (`clickPowerSword`)
* `Power_Sword = state.upgrades_combat.sword == 0 ? 0 : Math.floor(2 * (1.15 ^ state.upgrades_combat.sword))`
* `Power_Shield = state.upgrades_combat.shield == 0 ? 0 : Math.floor(8 * (1.17 ^ state.upgrades_combat.shield))`
* `Power_Armor = state.upgrades_combat.armor == 0 ? 0 : Math.floor(32 * (1.19 ^ state.upgrades_combat.armor))`
* **Итоговый урон по Боссам:** `clickPowerSword = 1 + Power_Sword + Power_Shield + Power_Armor`

### В. Базовые цены и шаг инфляции карточек
`CurrentCost = Math.floor(BaseCost * (Multiplier ^ CurrentLevel))`
* Кирка: `BaseCost = 15`, `Multiplier = 1.21` | Каска: `BaseCost = 150`, `Multiplier = 1.23` | Динамит: `BaseCost = 1200`, `Multiplier = 1.25`
* Меч: `BaseCost = 20`, `Multiplier = 1.22` | Щит: `BaseCost = 200`, `Multiplier = 1.24` | Доспех: `BaseCost = 1800`, `Multiplier = 1.26`
* Пахом: `BaseCost = 40`, `Multiplier = 1.24` | Бригада: `BaseCost = 400`, `Multiplier = 1.26` | Голем: `BaseCost = 3500`, `Multiplier = 1.28`

## 4. ТИКТОК-ВИРАЛЬНОСТЬ И ASMR-ЭФФЕКТЫ (JUICINESS)

### А. Скрипт расчета Комбо-Множителя
* При каждом клике JS проверяет разницу во времени между текущим и прошлым кликом (`Date.now() - state.lastClickTime`).
* Если разница **меньше 300ms**, `state.comboCount++`. Если больше 300ms — сброс `state.comboCount = 0`.
* При достижении `comboCount >= 10`: на экране загорается индикатор `COMBO x2`. Урон клика временно удваивается.
* При достижении `comboCount >= 25`: включается режим `HYPER COMBO`. Игровому контейнеру `.game-world` добавляется CSS-класс `.screen-shake` (микротряска экрана), а количество вылетающих партиклов осколков удваивается.

### Б. Визуальный отклик клика (Партиклы)
Каждое нажатие генерирует динамические `div`-элементы в точке `clientX/clientY`:
* По стенам: 4 серых квадратных осколка, разлетающихся по случайной параболе вниз.
* По монстрам: Огненные искры.
* По Кристаллу (50 ур.): Сияющие фиолетовые частицы.

## 5. ЛОГИКА КОНВЕЙЕРА И МОНЕТИЗАЦИЯ YANDEX SDK

*   **Здоровье Стен:** `HP = Math.floor(12 * (1.16 ^ checkpoint))`
*   **Здоровье Боссов:** `HP = Math.floor(65 * (1.26 ^ checkpoint))`
*   **Автопродажа:** Каждые 2 секунды начисляется пассивный доход. Интерфейс магазина обновляется точечно.

### Логика Босса и Межстраничная реклама (Правила Яндекса)
* На 5-й стене стейт переходит в `'BOSS_WAIT'`. Активируется кнопка **[ВЫЗВАТЬ БОССА]**.
* Бой длится 30 секунд. При проигрыше таймера или нажатии кнопки "Сбежать на фарм" триггерится вызов `AdManager.showInterstitial()`, но не чаще одного раза в 2 минуты (защита от бана модерации Яндекса). Игрок возвращается на фарм стен текущего уровня без потери прогресса.

## 6. ТЕХНИЧЕСКИЕ ДИРЕКТИВЫ ДЛЯ КЛИЕНТА (CLINE RULES)
* Весь код писать на чистых ES6 классах (`State.js`, `Engine.js`, `DialogueManager.js`, `UI.js`).
* Запрещено использовать тяжелые JS-библиотеки. Вся анимация комбо и сдвига параллакса реализуется через легковесные CSS keyframes и переключение классов.
* Магазин должен быть разделен на 3 графические вкладки (`[⛏️ ДОБЫЧА]`, `[⚔️ БОЙ]`, `[👥 НАЙМ]`). Заблокированные карточки выводить с прозрачностью `opacity: 0.5` и текстом заглушки замка.
